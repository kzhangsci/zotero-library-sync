# 数据、凭据与恢复

安装器和离线测试不访问真实 Zotero/Library，不读取现有凭据，不请求模型。
实际同步由用户在预演后明确确认：原始 PDF 发送给所选解析服务；待质检/翻译文本
发送给用户所选模型服务。相关授权、数据使用条件及费用由用户服务账户承担。

Zotero 本地 API、解析和模型密钥在首次运行时由用户授权/输入。Windows 当前用户
DPAPI 加密文件保存在配置的 `data/.secrets`；macOS 的密钥存于系统 Keychain，`.keychain` 文件仅记录随机引用；连接描述符也在该目录并受用户 ACL
限制。不要发布该目录。DPAPI 文件不能视为可跨用户/跨机器复制的明文凭据备份。
网络诊断不要附上 token、Authorization、模型请求正文或真实文献内容。

配置可以移动状态目录与 Library；`REPO` 始终表示代码。新安装 DATA 初始化独立本地
Git，且忽略凭据和缓存；只有明确传入初始化选项才创建 Library Git。均不设 remote、
不上传 GitHub、不修改 Zotero 数据库或全局 Git 配置，不自动改变全局代理/环境变量。
解析/模型服务域名由用户配置；安装包更新源尚未部署，XPI 使用保留 `.invalid` URL。

保留原 PDF、批注副本及 Library 历史。安全暂停必须等待当前受保护步骤完成，不能
把发出暂停请求当作已经停止。删除旧安装前先保留 data、Library 与必要报告；
本预览安装器没有自动清理或卸载行为。
